# Adaptive Energy Brain — Static Demo

A responsive, single-page concept demo for an AI-assisted renewable energy management system.

## Run locally
Open `index.html` in a modern browser. No build step or dependencies are required.

## Publish with GitHub Pages
1. Create a new public GitHub repository, e.g. `adaptive-energy-brain-demo`.
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish. The public demo URL will look like:
   `https://YOUR-USERNAME.github.io/adaptive-energy-brain-demo/`

## Important
All values are illustrative and synthetic. The page does not connect to a live grid, fetch live weather, or run a trained forecasting/RL model. Do not present the sample numbers as measured savings or validated results.
